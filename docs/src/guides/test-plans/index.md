# Test Plans

This section will guide you through writing a test plan for rtf from a blank file. The test plan
will be a simple "Hello, World!" example that introduces you to the concepts of writing RTF test
plans. For examples of test plans that can be used for specific testing use cases, please refer to
the [morgue][0].

## Prerequisites

We recommend completing the ["Hello, World!"](../hello-world.md) guide first to ensure you're
familiar with the rtf CLI and have it properly installed.
