# The Apollo Runtime Testing Framework Book

This is an [mdbook](https://rust-lang.github.io/mdBook/index.html) book containing user
facing documentation for how to work with the Apollo Runtime Testing Framework.


### Running the docsite locally

Ensure that you have a working Rust installation (see https://rustup.rs/ for details)
and then run the following in this directory:

```bash
$ cargo install mdbook
$ mdbook serve
```

The book should then be viewable in a web browser at `http://localhost:3000`.
