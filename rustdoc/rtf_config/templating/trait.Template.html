Expand description

In order to support controlled templating of config files with Scalar variables we make use of a wrapper Field type to identify where variables need to be injected. A type that implements Template supports walking its contents to locate and template fields using a provided map of scalar variables.

fn try_template_nested( &mut self, path: &mut Vec<String>, tail: &str, file_source: &StableSource, ctx: &TemplateContext, ) -> Result<()>

Attempt to resolve all pending Fields when this type is a child of some parent Template, appending encountered errors to the errs vec provided. The provided tail will be appended to path before calling through to Template::try_template.

fn try_template_known( &mut self, path: &mut Vec<String>, file_source: &StableSource, ctx: &TemplateContext, ) -> Result<Vec<String>>

Attempt to resolve all known Fields, reporting required variables that are not present in the provided map. If there are any deserialization errors then then this method as an aggregate operation will fail.
