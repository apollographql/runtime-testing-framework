Macro impl_template

Source 
macro_rules! impl_template {
    ($type:ty => []) => { ... };
    ($type:ty => [$first_field:ident $(, $field:ident)*]) => { ... };
}
Expand description

Helper for implementing the Template trait for types that only contain Fields at the top level. For types that contain collections of fields (e.g. Vecs and Maps) we need to write the implementation by hand.

§Usage

ⓘ
struct MyStruct {
    foo: Field<String>,
    bar: Field<usize>,
}

impl_template!(MyStruct => [foo, bar]);
