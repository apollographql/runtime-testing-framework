Expand description

An API client that can make requests to the GitHub REST API.

Required Methods§

Source

async fn raw_file_content( &self, org: &str, repo: &str, path: &str, git_ref: Option<impl AsRef<str>>, ) -> Result<Bytes, Error>

Attempt to pull the raw file content of a given file as [Bytes] from the specified GitHub repo.

The API token used to create this client must have access to the repo in question.

Provided Methods§

Source

async fn string_file_content( &self, org: &str, repo: &str, path: &str, git_ref: Option<impl AsRef<str>>, ) -> Result<String, Error>

Attempt to pull the raw file content of a given file as a utf-8 String from the specified GitHub repo.

The API token used to create this client must have access to the repo in question.
