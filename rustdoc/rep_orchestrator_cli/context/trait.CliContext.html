async fn run_shell( &self, cmd: &mut Command, next_execution_status: Status, ) -> Result<(), CliError>

Run an orchestration shell Command to completion.

On success, posts an update moving the execution to next_execution_status. On failure, returns a [Status::Unrunnable] error — every caller is an orchestration subroutine, so there is no distinction between “setup failed” and “user scenario failed” here.
