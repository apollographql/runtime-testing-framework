KnownTestPlanListParams
Query parameters accepted by GET /test-plan. Shared between the orchestrator’s axum Query extractor (deserializing an inbound request) and the UI’s outbound request builder (serializing these as the request’s query string) so the two sides can’t drift apart.
KnownTestPlanListResponse
A page of KnownTestPlanSummarys matching a set of query filters, along with the total number matching those filters (ignoring pagination) so that callers can page through the full result set.
KnownTestPlanRunsParams
Query parameters accepted by GET /test-plan/{uuid}/runs. Shared between the orchestrator’s axum Query extractor and the UI’s outbound request builder, as with KnownTestPlanListParams.
KnownTestPlanSummary
A Test Plan registered with the orchestrator, identifiable by UUID or name for triggering and for querying its historic runs.
