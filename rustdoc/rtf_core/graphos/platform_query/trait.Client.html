An API client that can make requests to the Apollo platform API.

Required Methods§

Source

async fn post_operation(&self, body: &impl Serialize) -> Result<Value, Error>

POST a GraphQL operation to the studio API with appropriate headers, returning the raw JSON response.

Client::execute_operation is used to handle creating the POST body and parsing the response.
