# rtf-orchestrator-ui

Helm chart for the orchestrator status UI

## Values

| Key                    | Type   | Default                                                                                                                                                   | Description                                                                                                                                           |
| ---------------------- | ------ | --------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------- |
| config                 | object | `{"host":"0.0.0.0","logLevel":"warn","orchestratorUrl":"","port":"8080"}`                                                                                 | Application configuration                                                                                                                             |
| config.host            | string | `"0.0.0.0"`                                                                                                                                               | Host address the server listens on                                                                                                                    |

| config.orchestratorUrl | string | `""`                                                                                                                                                      | Base URL of the orchestrator API the UI reads (e.g. http://rtf-orchestrator:8035). | config.port            | string | `"8080"`                                                                                                                                                  | Port the server listens on                                                                                                                            |

| grafana.dashboardUid   | string | `""`                                                                                                                                                      | UID of the dashboard deep links point to.
