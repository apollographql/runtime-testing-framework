# Runtime Testing Framework - CLI

The command line interface for the Apollo Runtime Testing Framework.

[JSON schema][0] files for each of the RTF config file formats can be found in the [json_schema][1]
directory to help with writing and linting Test Plans. The [Redhat YAML language server][2] can use
these schema files to provide completions and validation within your text editor or IDE.

Pre-generated shell completion files are available in the [shell_completions][3] directory. Please
see the relevant documentation for your shell for details on how to install the completion files for
your system.

[0]: https://json-schema.org/
[1]: ./json_schema
[2]: https://github.com/redhat-developer/yaml-language-server?tab=readme-ov-file#clients
[3]: ./shell_completions
